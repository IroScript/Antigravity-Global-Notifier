When using the `az restore-point create` command in the Azure CLI, the `--consistency-mode` parameter is **optional**[1][2].

If you omit the `--consistency-mode` parameter, the operation will proceed using the default behavior[3]. Currently, **`CrashConsistent`** is the standard consistency mode used by default when no specific mode is provided[3][4].

### Summary of Usage
*   **Default Behavior:** If you run `az restore-point create --resource-group <rg> --collection-name <collection> --name <rp-name>`, it will default to `CrashConsistent`[1][2][3].
*   **Explicit Usage:** You only need to include `--consistency-mode CrashConsistent` if you wish to explicitly define it in your script or command[1][5]. 

For further details on restore points, you can refer to the official [Azure Restore Points documentation](https://aka.ms/RestorePoints)[6][7].
