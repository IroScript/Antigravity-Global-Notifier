When sharing files and folders in Google Drive, there are four primary permission roles that determine what a user can do with the content[1][2].

### **Google Drive Permission Roles**

| Role | Can View? | Can Comment? | Can Edit? | Can Share/Manage Permissions? |
| :--- | :---: | :---: | :---: | :---: |
| **Viewer** | Yes | No | No | No |
| **Commenter** | Yes | Yes | No | No |
| **Editor** | Yes | Yes | Yes | Yes (by default) |
| **Owner** | Yes | Yes | Yes | Yes (Full Control) |

---

### **Detailed Role Breakdown**

*   **Viewer:** The most restrictive role. Users can open and read files, download, print, or copy them (unless the owner has restricted these options)[1][2][3]. They cannot change content or share the file with others[1][2].
*   **Commenter:** Includes all Viewer privileges plus the ability to add, reply to, and resolve comments and suggestions[1][2]. They cannot directly modify the file content[2][3].
*   **Editor:** Allows users to change content, accept/reject suggestions, and add or remove other people (unless the owner restricts this capability)[1][2][4]. They have the most collaborative power but cannot change the file owner[1].
*   **Owner:** The user who created the file or was transferred ownership. They have full control, including the ability to delete the file permanently, change sharing permissions, and transfer ownership to others[1][2][3].

### **Important Concepts**
*   **Inherited Permissions:** If you share a folder, all files and subfolders within that folder inherit the same permissions[1][5]. You cannot give someone "less" access to an individual file inside a folder if they already have "higher" access to the parent folder[1].
*   **Restricting Access:** Owners can further limit permissions by disabling the ability for Viewers and Commenters to download, print, or copy files via the **Share > Settings** menu[1][3].
*   **Shared Drives:** If you are working in a **Shared Drive** (rather than "My Drive"), roles work slightly differently and include levels such as *Content Manager* and *Manager*, which are designed for team-based file management[6][7].
