The `az restore-point collection create` command is used in the Azure CLI to create or update a restore point collection for virtual machines[1][2].

### Key Details
*   **Purpose:** This command initializes a restore point collection, which is a required container for creating individual VM restore points[1][2].
*   **Updating:** When using this command to update an existing collection, note that **only tags** may be modified[3][1].
*   **Key Parameters:**
    *   `--location`: The region where the restore point collection will be stored[2].
    *   `--source-id`: The resource ID of the virtual machine you are protecting[2].
    *   `--instant-access`: A parameter that enables instant access, allowing for faster disk restoration (applicable to specific disk types like Premium SSD v2 or Ultra disks)[4][5].

### Example Usage
To create a restore point collection, you typically run a command similar to the following:

```bash
az restore-point collection create \
  --location "eastus" \
  --resource-group "MyResourceGroup" \
  --collection-name "MyRestorePointCollection" \
  --source-id "/subscriptions/{sub-id}/resourceGroups/{rg}/providers/Microsoft.Compute/virtualMachines/{vm-name}"
```

For more detailed information and the full list of supported arguments, you can refer to the official [Microsoft Learn documentation for `az restore-point collection`](https://learn.microsoft.com).
