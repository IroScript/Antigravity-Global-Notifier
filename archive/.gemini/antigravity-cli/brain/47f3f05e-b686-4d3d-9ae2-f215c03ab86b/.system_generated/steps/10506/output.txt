**Antigravity CLI** is a terminal-based interface for Google’s "Antigravity" agent-first development platform, designed as the successor to the deprecated Gemini CLI.

### **Key Concepts & Directory Structure**
Antigravity CLI uses a hierarchical configuration and plugin system. When you install plugins (which contain skills, agents, rules, and MCP servers), they are typically staged in your home directory.

*   **Plugin Directory Structure:**
    `~/.gemini/antigravity-cli/plugins/<plugin_name>/`
    *   `plugin.json`: Required marker file.
    *   `skills/`: Optional agent skills.
    *   `agents/`: Optional subagents.
    *   `rules/`: Optional rules.
    *   `mcp_config.json`: Optional MCP server definitions.
    *   `hooks.json`: Optional event hooks definition.

*   **Skill Locations:**
    The system looks for skills in three primary scopes:
    1.  **Workspace Scope:** `~/your_project/.agents/skills/{skill_name}/SKILL.md`
    2.  **Global Scope:** `~/.gemini/antigravity-cli/skills/{skill_name}/SKILL.md`
    3.  **Shared Scope:** `~/.gemini/skills/{skill_name}/SKILL.md`

*   **Settings:**
    Persistent configurations are stored in `~/.gemini/antigravity-cli/settings.json`. You can manage settings within the CLI by typing `/config` or `/settings`.

### **What are "Skills"?**
"Skills" are reusable packages of instructions and assets that teach the Antigravity agent how to perform specific jobs. Instead of re-explaining a workflow, you can invoke a skill to apply pre-defined know-how. They are defined by a `SKILL.md` file within a designated folder.

### **Migration from Gemini CLI**
If you are transitioning from the retired Gemini CLI, Antigravity CLI supports a one-time import to migrate your existing extensions, skills, and settings. You can initiate this via:
*   **Automatic:** Handled during first-launch onboarding.
*   **Manual:** Using the `agy plugin import gemini` command.

### **Quick Reference**
*   **Command:** `agy`
*   **Update:** `agy update`
*   **Help/Slash Commands:** Type `?` or `/help` within the CLI to see available commands.
*   **Performance:** Uses the same underlying agent harness as Antigravity 2.0 (desktop app), allowing for seamless integration and shared settings.
