For tasks related to resetting, uninstalling, or cleaning configurations in the Antigravity (AGY) CLI, refer to the following documented commands and procedures:

### **Resetting and Cleaning**
*   **Reset Keybindings:** To reset your keybindings to their default state, delete the `keybindings.json` file located at `~/.gemini/antigravity-cli/keybindings.json`[1].
*   **Clear Conversation History:** Use the slash command `/clear` to clear the current prompt and start a new conversation session[1].
*   **Delete Conversations:** To remove obsolete threads, highlight the conversation in the picker and press `Ctrl + Delete`[2].
*   **Clear Screen:** Press `Ctrl + L` to clear the terminal output[1].

### **Uninstalling**
*   **Uninstall Plugins:** To remove a plugin and clean up its associated configuration registries, use the command[3]:
    ```bash
    agy plugin uninstall <plugin_name>
    ```

### **Execution Modes & Defaults**
*   **Default Mode:** The CLI operates in `default` mode by default, which pauses for interactive diff reviews before applying changes[4]. You can cycle between `default`, `accept-edits`, and `plan` modes using `Shift + Tab` within the prompt box[4].
*   **Settings:** Configurations are categorized into four scopes to keep settings "clean and isolated"[5]. By default, clicking **Settings** opens the configuration for the active project, or the global settings if no project is open[5].
