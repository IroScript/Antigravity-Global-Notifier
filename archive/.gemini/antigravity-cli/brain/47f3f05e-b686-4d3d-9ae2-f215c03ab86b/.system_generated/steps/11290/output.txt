For Azure Linux virtual machines, `azureuser` is a common default username often suggested during the creation process, though you can specify a different username if you choose[1][2][3].

The home directory for this user (or any user created during the VM provisioning process) is located at:

**/home/azureuser**[4][5]

### Key Details:
*   **Customization:** While `azureuser` is the default recommendation in the Azure portal and CLI documentation, it is not a hard requirement; you can define a different administrative username during VM deployment[1][2].
*   **Home Directory Path:** Consistent with standard Linux conventions, the home directory for a user named `username` will be `/home/username`[6][4].
*   **Deletion:** If you use the Azure CLI command `az vm user delete` to remove a user account, the associated home directory on the Linux VM is also deleted[7].
