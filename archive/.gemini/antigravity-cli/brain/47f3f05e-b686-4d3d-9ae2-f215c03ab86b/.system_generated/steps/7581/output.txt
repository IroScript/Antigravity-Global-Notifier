To create a snapshot using the Azure CLI, you use the `az snapshot create` command. The `--source` parameter is required to specify the source of the snapshot, which can be a Managed Disk ID, a snapshot ID, or a blob URI[1][2][3].

### Basic Command Syntax
```bash
az snapshot create \
    --resource-group <resource-group-name> \
    --name <snapshot-name> \
    --source <source-id-or-uri>
```

### Key Parameters
*   **`--resource-group` (`-g`)**: The name of the resource group where the snapshot will be created[1].
*   **`--name` (`-n`)**: The name of the snapshot[1].
*   **`--source`**: The identifier of the source. This can be:
    *   **Managed Disk ID**: Typically retrieved using `az vm show`[2][3].
    *   **Snapshot ID**: Used when creating an incremental snapshot or copying a snapshot[4][5].
    *   **Blob URI**: Used when importing from a VHD stored in a storage account[1].

### Common Examples

**1. Create a snapshot from a VM's OS Disk**
First, get the disk ID, then create the snapshot[3]:
```bash
# Get the OS disk ID
osdiskid=$(az vm show -g MyResourceGroup -n MyVM --query "storageProfile.osDisk.managedDisk.id" -o tsv)

# Create the snapshot
az snapshot create -g MyResourceGroup -n MySnapshot --source "$osdiskid"
```

**2. Create an incremental snapshot**
Incremental snapshots are efficient for backups of managed disks[6].
```bash
az snapshot create -g MyResourceGroup -n MySnapshot --source <disk-id> --incremental true
```

**3. Create a snapshot from a blob URI**
```bash
az snapshot create -g MyResourceGroup -n MySnapshot --source https://vhd1234.blob.core.windows.net/vhds/osdisk1234.vhd
```

For more details and optional flags (such as `--sku`, `--location`, or `--incremental`), you can refer to the official [az snapshot documentation](https://learn.microsoft.com/en-us/cli/azure/snapshot?view=azure-cli-latest) on Microsoft Learn[1].
