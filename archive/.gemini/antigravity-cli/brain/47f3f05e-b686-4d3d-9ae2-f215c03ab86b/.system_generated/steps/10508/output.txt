In Google Antigravity, plugins are structured as directories containing a required `plugin.json` manifest file and optional subdirectories for various components[1][2][3]. When installed, these are typically staged in your home directory under `~/.gemini/antigravity-cli/plugins/<plugin_name>/`[3].

### Plugin Directory Structure
A typical plugin directory is organized as follows[2][3]:

*   `plugin.json`: **Required**. The manifest file identifying the directory as a plugin and defining its metadata[2][3].
*   `mcp_config.json`: Optional. Definitions for Model Context Protocol (MCP) servers[2][3].
*   `hooks.json`: Optional. Definitions for event hooks[2][3].
*   `skills/`: Optional. Subdirectories containing `SKILL.md` files for agent instructions[2][3].
*   `agents/`: Optional. Markdown files defining custom subagent templates[4][2][3].
*   `rules/`: Optional. Markdown files defining behavioral constraints or style guidelines[4][2][3].

### Related Configuration Structures

#### Sidecars
Sidecars are background processes managed by Antigravity[5]. They are discovered via `sidecar.json` files and can be located in[5]:
*   **Global:** `~/.gemini/config/sidecars/`
*   **Plugin-based:** `~/.gemini/config/plugins/<pluginName>/sidecars/`

Example sidecar directory structure[5]:
```text
~/.gemini/config/sidecars/
├── sidecar1/
│   ├── sidecar.json
│   └── script.py
└── sidecar2/
    └── sidecar.json
```

#### Skills
While skills can be part of plugins, they can also be managed globally or per-workspace[6]. The standard directory is `.agents/skills/`[6]. Each skill is a folder containing a `SKILL.md` file[6][7]:
```text
.agents/skills/
└── my-skill/
    ├── SKILL.md      # Required instructions
    ├── scripts/      # Optional helper scripts
    └── examples/     # Optional reference implementations
```
