When creating an Azure Virtual Machine, **"azureuser"** is a commonly suggested default username in Microsoft Learn documentation and tutorials[1][2][3], but it is **not a system-enforced default**[4].

### Key Points:
*   **No Automatic Default:** Azure does not automatically assign a "default" username to your VM[4]. When you create a VM, you are required to specify an administrator username[2][5]. 
*   **Common Convention:** Because "azureuser" is frequently used in Microsoft's own quickstarts and learning paths (such as the Azure Fundamentals exercises)[1][6], many users assume it is the standard default[7][8].
*   **Reserved Usernames:** While "azureuser" is a common suggestion, certain usernames are **disallowed** or reserved by the system (e.g., "root," "admin," "administrator," "test," etc.)[9]. If you attempt to use these, the provisioning process will fail[5][9].
*   **How to check or change your username:**
    *   **If you created the VM:** You likely set the username during the creation process (via the Azure Portal, CLI, or Template)[1][2][10].
    *   **If you forgot the username:** You can reset the credentials for the VM by navigating to the **"Reset password"** blade under the **"Support + troubleshooting"** section of your VM in the Azure portal[11][12]. This allows you to set a new username and password for the administrative account[12].
