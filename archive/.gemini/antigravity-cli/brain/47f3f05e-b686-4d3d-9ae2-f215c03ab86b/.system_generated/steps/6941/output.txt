The search for ""google drive" allow upload without delete permission OR "shared drive" roles" returned the following summary:
Google Drive does not natively provide a way to grant "upload-only" access to a folder that prevents the uploader from also deleting files[1][2][3]. In both standard folders and Shared Drives, the permission levels required to add files (Editor or Contributor) inherently include the ability to delete or modify content[1][4][5].

### Why this is restricted
*   **Inherited Permissions:** In Google Drive, permissions are inherited[6][7]. If you give someone "Editor" access to a folder so they can add files, that same access level applies to the files within it, allowing them to delete or move them[4][3].
*   **Shared Drive Roles:** While Shared Drives offer more granular roles than standard folders (Manager, Content Manager, Contributor, Commenter, Viewer)[8], none of these roles permit adding files without also granting the ability to edit or delete[5]. 
    *   **Contributors** can add and edit files[5].
    *   **Content Managers** (the default for many) can add, edit, move, and delete files[8].

### Recommended Workarounds
Because Google Drive does not support a native "drop-box" style permission, you can use these alternatives to achieve the same result:

1.  **Google Forms (Best for file collection):** Create a Google Form and add a "File Upload" question type[9]. This allows users to submit files to a folder you own without them needing access to the folder itself[9][3]. They will not be able to see, edit, or delete other people's submissions[6][9].
2.  **Third-Party Tools:** Services like *File Request Pro* or *PigeonFiles* are specifically designed to create "upload-only" portals for Google Drive[9][3]. These tools provide a link for users to upload files directly into your Drive without giving them any other access to your folders[10][3].
3.  **Individual Folder Sharing (If collaboration is required):** If you are working with a small, trusted team, have them create their own folders and share them with you[6][11]. You can then move these into your master folder[11]. This keeps the files under their ownership while still centralizing them for your view[6][11].
