The `az restore-point` command group in the Azure CLI is used to manage VM restore points, which allow you to protect data and guard against downtime by creating snapshots of virtual machines at regular intervals[1][2].

### Key Capabilities
*   **Management:** The `az restore-point` module enables you to create and manage restore points directly from the command line or via scripts[1][2].
*   **Restore Point Collections:** You can manage "restore point collections," which serve as containers for individual restore points[1][3]. 
*   **Flexibility:** Recent updates to the Azure CLI have added support for parameters such as encryption settings for both OS and data disks during the restore point creation process[4].
*   **Troubleshooting:** In scenarios where resource groups cannot be deleted due to "stuck" or corrupted restore point collections (often found in service-managed resource groups like `AzureBackupRG_<region>`), the `az restore-point collection` commands can be used to identify and manage these resources[5][3].

### Common Commands
*   `az restore-point create`: Used to create a new restore point for a virtual machine[6][4].
*   `az restore-point collection list`: Used to list restore point collections within a specific resource group, which is helpful for cleaning up orphaned resources[3].
*   `az restore-point collection delete`: Used to remove a restore point collection[5].

For detailed usage, tutorials, and parameter references, you can search for "az restore-point" directly on [Microsoft Learn](https://learn.microsoft.com)[1].
