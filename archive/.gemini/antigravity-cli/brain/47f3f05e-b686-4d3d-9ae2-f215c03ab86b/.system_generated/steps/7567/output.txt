The `az restore-point create` command in the Azure CLI is used to create a restore point for a virtual machine within an existing restore point collection[1][2].

### Basic Usage
To create a restore point, you must specify the resource group, the name of the restore point collection, and the name for the new restore point[1]:

```bash
az restore-point create \
    --resource-group "ExampleRg" \
    --collection-name "ExampleRpc" \
    --name "ExampleRp"
```

### Key Considerations
*   **Restore Point Collections:** Before creating a restore point, you must first create a "restore point collection" using `az restore-point collection create`[1][2].
*   **Consistency Modes:** You can optionally set the `--consistency-mode` parameter to `CrashConsistent` if you are creating a crash-consistent restore point (currently in preview)[1].
*   **Instant Access:** If your restore point collection has "Instant Access" enabled (supported for specific disk types like Premium SSD v2 or Ultra disks), you can specify the `--instant-access-duration` parameter[1][3].
*   **Immutability:** Once a restore point is created, its properties cannot be updated[4][5].
*   **Monitoring Progress:** You can track the status of the creation process using the `az restore-point show` command[6].

### Recent Updates
Recent updates to the Azure CLI have added support for disk encryption during the restore point creation process, including parameters such as `--os-restore-point-encryption-set`, `--os-restore-point-encryption-type`, `--data-disk-restore-point-encryption-set`, and `--data-disk-restore-point-encryption-type`[7].
