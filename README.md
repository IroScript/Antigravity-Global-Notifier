# Antigravity Global Notifier & Directives (অ্যান্টিগ্র্যাভিটি অটো-নোটিফিকেশন ও গ্লোবাল রুলস)

এই রিপোজিটরিতে Google Antigravity (AGY) এর গ্লোবাল লাইফসাইকেল হুক্স (Lifecycle Hooks), টার্মিনাল রিপ্লাই অটো-নোটিফিকেশন স্ক্রিপ্ট (উইথ সাউন্ড এবং ৫ মিনিট স্নুজ ফিচার) এবং গ্লোবাল এজেন্ট রুলস সংরক্ষিত রয়েছে।

---

## ⚡ মূল সুবিধাসমূহ (Key Features)

1. **Every Reply Alert (প্রতিটি রিপ্লাইয়ে অ্যালার্ট):**
   - যেকোনো টার্মিনালে এজেন্টের রিপ্লাই শেষ হওয়ামাত্রই অডিও সাউন্ড বাজবে এবং স্ক্রিনের সবার উপরে ফোকাসড পপআপ ডায়ালগ আসবে।

2. **Multi-Terminal Workspace Identifier (মাল্টি-টার্মিনাল ডিটেকশন):**
   - আপনি একসাথে ১০+ টার্মিনালে `agy` চালালেও পপআপে পরিষ্কারভাবে দেখিয়ে দেবে **কোন প্রজেক্ট/ফোল্ডারের** টার্মিনালটি রিপ্লাই দিয়েছে।

3. **5-Minute Snooze Capability (৫ মিনিটের স্নুজ):**
   - তাৎক্ষণিক ইনপুট দিতে না পারলে `⏰ ৫ মিনিট স্নুজ (Snooze 5m)` বাটনে ক্লিক করলে ৫ মিনিট পর আবার সাউন্ড দিয়ে মনে করিয়ে দেবে।

4. **Auto Folder Title & Random Tab Color (টার্মিনাল অটো-রিনেম ও র‍্যান্ডম কালার):**
   - যেকোনো ফোল্ডারে টার্মিনাল ওপেন করলে বা `cd` করলে স্বয়ংক্রিয়ভাবে সেই ফোল্ডারের নাম টার্মিনাল ট্যাবের টাইটেলে সেট হয়ে যায়।
   - প্রতিবার নতুন টার্মিনাল ওপেন করার সাথে সাথে আগের টার্মিনাল থেকে ভিন্ন একটি আকর্ষণীয় র‍্যান্ডম কালার ট্যাবে অ্যাসাইন হয়।

5. **1-Click Easy Installation (১-ক্লিকে ইনস্টলেশন):**
   - যেকোনো নতুন পিসি বা সিস্টেমে কেবল `install.bat` ডাবল-ক্লিক করলেই স্বয়ংক্রিয়ভাবে সমস্ত হুক, নোটিফায়ার এবং টার্মিনাল কাস্টমাইজার সেটআপ হয়ে যাবে।

## 📂 ফাইলসমূহের তালিকা

* `notify_reply.py` - সাউন্ড, প্রজেক্ট ডিটেকশন ও ৫ মিনিটের স্নুজ সহ Tkinter UI স্ক্রিপ্ট।
* `hooks.json` - অ্যান্টিগ্র্যাভিটি ইঞ্জিনের গ্লোবাল লাইফসাইকেল হুক কনফিগারেশন (`Stop` ইভেন্ট)।
* `terminal_customizer.ps1` - ফোল্ডার অনুযায়ী অটো টার্মিনাল নাম (ইন-প্রসেস C# TitleGuardian) ও র‍্যান্ডম কালার সেট করার স্ক্রিপ্ট।
* `Project_Launcher/` - ⚠️ *(Side Note: Prototype / প্রোটোটাইপ - বর্তমানে উন্নয়নের কাজ চলমান)*।
* `AGENTS.md` - গ্লোবাল এজেন্ট ডিরেক্টিভস ও সিস্টেম রুলস।
* `GEMINI.md` - গ্লোবাল অ্যাসিস্ট্যান্ট নির্দেশিকা।
* `install.bat` - ১-ক্লিকে লোকাল কনফিগে সেটআপ করার ব্যাচ স্ক্রিপ্ট।
