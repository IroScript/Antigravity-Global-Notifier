==================================================
PROBLEM

The WhatsApp Bridge is receiving messages from WhatsApp and forwarding them to the local CLI.

But messages generated by automation, another bridge, bot, CLI, telemetry system, terminal reporter, or other non-human source can also arrive in the same WhatsApp group.

Those messages are being interpreted as genuine user prompts.

This can create:

WhatsApp message
→ Bridge
→ CLI
→ WhatsApp output
→ Bridge
→ CLI
→ WhatsApp output
→ ...

This recursive execution MUST become architecturally impossible.

→ WhatsApp

→ WhatsApp
