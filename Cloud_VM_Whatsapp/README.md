# Cloud VM WhatsApp Bridge (Antigravity Global Notifier)

## 📌 সারসংক্ষেপ
এই মডিউলটি লিনাক্স ক্লাউড ভিএম (Azure VM)-এ চালিত Google Antigravity CLI (`agy`)-কে হোয়াটসঅ্যাপের সাথে সার্বক্ষণিক ২-ওয়ে (দ্বিমুখী) যোগাযোগে সংযুক্ত রাখে।

## 📁 মূল উপাদানসমূহ:
1. `whatsapp_bridge.js`: Baileys প্রটোকল ভিত্তিক নোড ইঞ্জিন। হোয়াটসঅ্যাপ থেকে বার্তা গ্রহণ করে tmux সেশনে কমান্ড ইনজেক্ট করে এবং এজিওয়াই ব্রেন ডিরেক্টরির লাইভ ট্রান্সক্রিপ্ট রিড করে হোয়াটসঅ্যাপে লাইভ স্ট্রিমিং ও রেসপন্স পাঠায়।
2. `init_agy_sessions.sh`: ক্লাউড ভিএম-এ ১২টি ভিন্ন প্রজেক্ট উইন্ডো সহ `agy` tmux সেশন স্বয়ংক্রিয় তৈরি ও প্রস্তুত করার স্ক্রিপ্ট।
3. `agy-whatsapp.service`: ২৪ ঘণ্টা ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে চালু রাখার সিস্টেমডি সার্ভিস কনফিগারেশন।
4. `boundary_guard.py`: সিকিউরিটি ও বাউন্ডারি গার্ড স্ক্রিপ্ট।
