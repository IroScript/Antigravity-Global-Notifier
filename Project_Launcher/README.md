# 🚀 Project Launcher & Work Orchestrator for Antigravity (AGY)

> ⚠️ **PROTOTYPE NOTICE (প্রোটোটাইপ নোট):** 
> এই মডিউলটি বর্তমানে **প্রোটোটাইপ (Prototype)** অবস্থায় আছে এবং এর সব ফিচার এখনও পুরোপুরি কার্যকর নয়। উন্নয়নের কাজ চলমান রয়েছে।

একটি আল্ট্রা-লাইটওয়েট **Multi-Project Terminal Launcher, Visual Color Identity Engine, এবং Universal Audio/Visual Notification System**।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **🎨 প্রজেক্ট-ভিত্তিক টার্মিনাল কালার থিম (Visual Identity):**
   - প্রতিটি প্রজেক্টের জন্য সম্পূর্ণ আলাদা ব্যাকগ্রাউন্ড কালার (DarkRed, DarkBlue, DarkGreen, DarkMagenta, DarkCyan, DarkYellow ইত্যাদি)।
   - ৫-১০টি টার্মিনাল একসাথে খোলা থাকলেও এক দেখাতেই বোঝা যাবে কোনটি কোন প্রজেক্ট।
   - উপরে বড় করে প্রজেক্ট হেডার ও লাইভ পাথ দৃশ্যমান থাকে।

2. **⚡ ইনস্ট্যান্ট ১-ক্লিক লঞ্চার:**
   - কোনো ফোল্ডার বা পাথ মনে রাখার প্রয়োজন নেই।
   - ১ চাপলে YouTube Pipeline, ২ চাপলে AI Agent ইত্যাদি সরাসরি ওপেন হয়ে `agy` শুরু হবে।

3. **➕ ডাইনামিক প্রজেক্ট ম্যানেজার:**
   - মেনু থেকে `[A]` চাপলে সহজেই যেকোনো নতুন ফোল্ডার বা প্রজেক্ট যোগ করা যায়।
   - সব প্রজেক্ট `projects_config.json` ফাইলে স্থায়ীভাবে সংরক্ষিত থাকে।

4. **🔔 ইউনিভার্সাল মাদার-ফোল্ডার নোটিফিকেশন (`notify.ps1`):**
   - কোনো প্রজেক্টে এআই কাজ শেষ করলে সাথে সাথে সাউন্ড বাজবে এবং স্ক্রিনে মাদার ফোল্ডারের নাম সহ **"OK"** ডায়ালগ বক্স ভেসে উঠবে।
   - আপনি **OK** বাটনে ক্লিক না করা পর্যন্ত এটি দৃশ্যমান থাকবে।
