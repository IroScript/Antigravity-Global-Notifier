# RULE 09: UNIVERSAL LANGUAGE & COMMUNICATION GOVERNANCE

## CORE MANDATE: PURE BENGALI SCRIPT (বাংলা) ONLY, STRICT BAN ON BANGLISH

This governance rule establishes mandatory communication standards for all AGY agents (`agy:0`, `agy:ask`, `agy:report`, `agy:action`, Antigravity CLI, WhatsApp Bridge, and OpenAI Codex).

---

### 1. `RULE_09_01_MANDATORY_BANGLA_SCRIPT`
- **Mandate**: All user-facing communications, conversational text, explanations, analytical summaries, status updates, and progress reports MUST be written in authentic Bengali language using standard Bengali script (বাংলা বর্ণমালা ও লিপি).
- **Quality**: The Bengali must be clear, natural, grammatically correct, and formal standard Bengali (প্রমিত বাংলা).

---

### 2. `RULE_09_02_ABSOLUTE_BAN_ON_BANGLISH`
- **Strict Prohibition**: Writing Bengali phonetically using English/Latin alphabet (Banglish / Romanized Bengali, such as *"Ami kaj shuru korechi"*, *"Eta thik ache"*, *"Apnar request process hocche"*) is **STRICTLY FORBIDDEN** across all agents and channels without exception.
- Any message generated in Banglish is classified as a policy violation and non-compliant output.

---

### 3. `RULE_09_03_CODE_AND_TECHNICAL_SYNTAX_PRESERVATION`
- **Technical Integrity**: To ensure zero syntax errors and 100% operational precision, the following technical assets MUST retain their standard English syntax:
  - Source code, scripts, and code blocks (````python`, ````bash`, ````javascript`, ````rust`, etc.).
  - File system paths (`/home/azureuser/...`, `~/.webterminal/...`).
  - Terminal commands, options, and flags (`git commit`, `curl -I`, `systemctl --user status`).
  - Configuration keys, environment variables, and JSON objects (`"project_id"`, `"status"`).
  - Cryptographic hashes, nonces, and verbatim error logs / tracebacks.

---

### 4. `RULE_09_04_UNIVERSAL_AGENT_SCOPE`
- This rule applies universally to:
  - Master Supervisor Agent (`agy:0`)
  - Ask & Research Agent (`agy:ask`)
  - Reporting & Monitoring Sentinel (`agy:report`)
  - Action & Incident Fixer (`agy:action`)
  - WhatsApp Bridge dispatchers and auto-responders
  - OpenAI Codex agent and subagents
